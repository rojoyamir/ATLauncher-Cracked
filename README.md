## English


ATLauncher Offline is a compact fork of [ATLauncher/ATLauncher](https://github.com/ATLauncher/ATLauncher) focused on local offline accounts, portable use, and modpack management.


### 🚀 Quick Start

1. Download the latest build from [Releases](../../releases).
2. Run `ATLauncher-Offline-*.exe`.
3. Create a local username.
4. Install or import a modpack.
5. Launch in offline single-player mode.

Profiles, settings, and instances are stored locally near the launcher.
